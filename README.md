# OpenGL-Linux
Simple C program using OpenGL (3D)

## 📎 Quick Start (Debian-like system only)
> Before installing/building the project, make sure you have: gcc, make installed
```
sudo apt-get install freeglut3-dev libglew-dev
sudo apt-get install imagemagick
git clone https://github.com/rediskazavr/opengl-linux
cd opengl-linux
chmod u+x build.sh
./build.sh
./app.run

```
